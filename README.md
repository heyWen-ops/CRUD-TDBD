# Conecta W&H - Administración de Inventario 📱✨

¡Bienvenido a **Conecta W&H**! Este es un sistema web diseñado para gestionar de manera integral el inventario de teléfonos móviles y el control de ventas de forma ordenada, intuitiva y visualmente atractiva.

El sistema organiza la información de los dispositivos dividiéndola de manera modular (Marcas, Modelos, Colores, Descripciones, Estados y Teléfonos) para evitar la duplicidad de datos y mantener un control exacto del flujo de ventas.

## 🚀 Características Principales

* **Módulos de Catálogo:** Registro y consulta de Marcas, Modelos, Colores y Estados.
* **Gestión de Descripciones:** Vinculación de características comerciales y asignación de precios base.
* **Control de Teléfonos:** Registro detallado de equipos individuales mediante su código IMEI y su estado actual.
* **Módulo de Ventas:** Registro de salidas de mercancía con precio final y generación de reportes semanales.
* **Interfaz Personalizada:** Diseño web responsivo basado en una paleta de colores armónica (tonos rosados/guinda) con tipografía moderna y transiciones fluidas.

## 🛠️ Tecnologías Utilizadas

* **Backend:** PHP utilizando la extensión **PDO (PHP Data Objects)** para una comunicación segura con la base de datos.
* **Base de Datos:** MySQL (con soporte para transiciones relacionales entre tablas).
* **Frontend:** HTML5 y CSS3 nativo (sin frameworks, con un enfoque en diseño limpio y adaptabilidad móvil).

## 📁 Estructura del Proyecto

* `conexionBD.php`: Configuración centralizada de la conexión a la base de datos mediante PDO.
* `index.php`: Panel principal o menú de administración del sistema.
* `estilos.css`: Hoja de estilos global que define la identidad visual del sitio.
* `controlador/`: Archivos encargados del procesamiento de datos y consultas lógicas.
* `vista/`: Formularios de registro e interfaces de visualización de tablas.
